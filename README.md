# Neon Flow

A glowing "connect the matching dots and fill the board" puzzle for Android, built with Flutter.

- **150 levels** in **15 stages** of 10: 50 Easy (5x5, 6x6), 50 Medium (7x7, 8x8), 50 Hard (8x8, 9x9)
- Sequential unlock, 1-3 stars per level (based on moves, hints cap at 2 stars), best-move tracking
- Undo, restart, hint (solves one colour), live fill %, win screen with confetti and animated stars
- 10 synthesised sound effects + haptics, both toggleable
- Monetisation with **runtime on/off switches**: AdMob banner, interstitial, rewarded (free hint) and Google Play hint packs

## First-time setup (macOS/Linux/Windows with Flutter installed)

```bash
cd neon_flow
bash tools/setup_android.sh     # creates android/, patches manifest + minSdk 23, makes launcher icon
flutter test                    # engine tests + validates all 150 levels
flutter run                     # run on a phone/emulator
```

The Android project files are generated by `flutter create` so they always match your installed Flutter version.

## Project layout

| Path | Purpose |
|---|---|
| `lib/core/game_engine.dart` | Pure game rules: drag, cut, backtrack, undo, hints, stars |
| `lib/core/level.dart` | Level model + loader, stages of 10 |
| `lib/core/app_config.dart` | **Ad unit IDs, IAP product IDs, remote-config URL** |
| `lib/core/monetization_config.dart` | Runtime switches (persisted, optional remote JSON) |
| `lib/core/ad_service.dart` | AdMob + UMP consent, interstitial, rewarded |
| `lib/core/iap_service.dart` | Google Play Billing consumables |
| `lib/ui/` | Home, stages, game, store, settings, glowing board painter |
| `assets/levels/levels.json` | The 150 levels (with stored solutions for hints) |
| `tools/generate_levels.py` | Regenerates/validates levels (`python3 tools/generate_levels.py`) |
| `tools/generate_sounds.py` | Regenerates the WAV sound effects |

## Turning monetisation on/off at runtime

Three ways, all persisted on the device:

1. **In the app:** Settings > long-press the "Neon Flow / Version" row > *Monetisation* switches (master ads, banner, interstitial, rewarded, hint packs, interstitial frequency). Visible automatically in debug builds.
2. **Remotely, no app update:** host a JSON file and put its URL in `AppConfig.remoteConfigUrl`:
   ```json
   {"adsEnabled": true, "bannerEnabled": true, "interstitialEnabled": true,
    "rewardedEnabled": true, "iapEnabled": true, "interstitialEvery": 3}
   ```
   It is fetched at each launch; failures are ignored and the last saved values are used.
3. **In code:** change the defaults in `MonetizationConfig`.

Before shipping, hide the in-app panel by setting `_devUnlocked = false` in `settings_screen.dart` if you don't want players to see it.

## Going live checklist

1. **AdMob:** create an app + 3 ad units (banner, interstitial, rewarded). Put the IDs in `AppConfig`, set `useTestAds = false`, and replace the test App ID (`ca-app-pub-3940256099942544~3347511713`) in `android/app/src/main/AndroidManifest.xml` with your real App ID.
2. **Play Console > Monetize > Products > In-app products:** create three managed products with IDs `hints_5`, `hints_20`, `hints_50` and activate them. Upload a build to an internal-testing track and add license testers to try purchases.
3. **AdMob consent (UMP):** configure a GDPR message in AdMob > Privacy & messaging. Code for the consent form is already included.
4. **Play Console policy:** add a privacy policy URL, complete the Data safety form (ads + purchases), and the Ads declaration.
5. **Signing + release:** follow https://docs.flutter.dev/deployment/android to create a keystore, then `flutter build appbundle --release` and upload `build/app/outputs/bundle/release/app-release.aab`.
6. Optional hardening: verify purchases server-side (currently granted on the client).

## Notes

- Levels are generated so that every one is solvable (each solution is stored and replayed by the unit test). Some levels can have more than one valid solution; any full fill wins.
- Rules: connect each colour pair, cover every cell. Dragging over another colour cuts it; drag back along your own line to undo part of it.
